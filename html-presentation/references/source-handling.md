# Sources, Evidence, and Deep Dives

Use this reference when the brain dump contains URLs, documents, research, metrics, quotations, external media, or factual claims that need provenance.

## During synthesis

Build a compact source ledger in the review plan. Give each source a stable identifier such as `[S1]`, `[S2]`, and record what it actually supports.

Distinguish among:

- externally verified fact;
- supplied internal fact;
- user opinion or goal;
- agent inference;
- unresolved or conflicting information.

Do not quietly convert an inference into a fact.

## In the presentation

The primary visual layer should not become a bibliography. Use provenance in proportion to the audience and claim:

- discreet source markers on sourced metrics or quotations;
- a `Sources` or `Details` action that opens the right drawer;
- source cards with title, origin, relevance, and external link;
- optional footnotes for claims where immediate attribution matters.

Keep raw URLs out of the main composition unless the URL itself is meaningful.

## External links

External hyperlinks are allowed in an offline presentation; clicking them simply requires connectivity. Set them up as explicit resources rather than hidden dependencies.

For links that matter during a live presentation, expose enough title/context that the presenter understands the destination before opening it.

## Images and media

Prefer user-supplied, licensed, or clearly reusable assets. Keep image provenance where appropriate.

For a truly single-file offline artifact, embed manageable local images as data URIs or reconstruct simple diagrams as inline SVG. Do not hotlink remote images as part of the core visual layer.

Embedded remote video players require a network connection even when the HTML itself is local. Use them only when requested and keep them nonessential to the presentation's core flow.

### Image Generation

If the agent tool manifest exposes image-generation capability, such as OpenAI's Image-gen model or similar offerings and the presentation would generally be improved with a AI generated visual, leverage it unless otherwise directed. 

## Conflicting sources

When sources disagree, surface the disagreement in the review plan. The presentation may show a range, caveat, or explicit uncertainty if that is materially important. Do not choose the prettier number.
