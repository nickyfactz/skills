# Documentation sync after a refactor

- Update README sections that describe architecture, setup, commands, or file
  layout.
- Update architecture notes, ADRs, or design docs that mention moved
  responsibilities.
- Update examples or snippets that import changed modules.
- Update comments that describe changed behavior or ownership.
- Remove stale migration notes when the migration is complete.
- Update test guidance when the testing strategy changes.
- Update generated-file instructions when build steps or code-generation paths
  change.
